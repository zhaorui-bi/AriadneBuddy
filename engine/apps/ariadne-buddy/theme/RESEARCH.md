# AriadneBuddy 界面设计

设计语言与令牌参考见仓库根目录的 [`docs/DESIGN.md`](../../../../docs/DESIGN.md)（中文镜像
[`docs/zh-CN/DESIGN.md`](../../../../docs/zh-CN/DESIGN.md)）。

古希腊风格从现有 Ariadne 肖像延伸到界面。品牌区使用线刻肖像、柱槽、柱础与双线，标题沿用衬线字体。正文、表格和按钮使用同一套系统无衬线字体；状态同时用文字和颜色呈现。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 工作区画布 | `#fbfbfa` | `#171717` |
| 侧栏 | `#f2f2f1` | `#1d1d1d` |
| 内容面板 | `#ffffff` | `#202020` |
| 主按钮（`--color-send-bg`） | `#1f5688` | `#a8cbe6` |

`appearance.css` 提供对话、任务会话、设置和桌面启动页共用的颜色、边线、字体和组件尺寸。
侧栏会话列表分为普通任务、已归档任务，以及独立的 AFPK 筛选分组（含各自归档），未决门禁带
「待决策」标记。会话正文依次显示研究目标、运行记录、结果和审核；计算、产物、轨迹三个页签
可从运行记录展开，审核表表头吸顶并支持打印留档。
